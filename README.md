## ✨ About Me

안정적이고 확장 가능한 서버 아키텍처를 설계하는 **9년 차 백엔드 개발자**입니다.
**Laravel**과 **Spring** 프레임워크를 주력으로 다루며, 견고한 비즈니스 로직 구현과
대용량 트래픽 처리, 데이터베이스 모델링 및 성능 최적화에 깊은 전문성을 가지고 있습니다.

단순한 기능 구현을 넘어, 서비스의 지속 가능한 성장을 뒷받침하는 튼튼한 시스템을 만드는 데 집중합니다.

⚙️ **Backend Architecture** | 🚀 **Performance Optimization** | 🌐 **API Design & Integration**
